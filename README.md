# Running TypeScript Code

## Prerequisites
Make sure you have [Node.js](https://nodejs.org/) and [TypeScript](https://www.typescriptlang.org/) installed.

## Steps

1. **Compile TypeScript Code**

   First, compile your TypeScript file (`index.ts`) to JavaScript using the TypeScript compiler (`tsc`). Run the following command:
